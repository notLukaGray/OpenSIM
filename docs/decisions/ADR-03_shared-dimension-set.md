# ADR-03 — One shared need dimension set

Date: 2026-08-23 · Status: accepted

Players, brands, archetypes, evidence effects, and modifiers all speak the SAME ten dimensions —
`control, readiness, reassurance, aspiration, belonging, mastery, comfort, excitement,
selfExpression, trust` — defined once in `game/types.ts` and mirrored by the validator. No second
vocabulary is ever introduced for a subsystem.

Consequence: every system composes with every other by construction; the reveal can compare player
weights directly against brand profiles.
